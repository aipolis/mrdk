# 明日当空 Lite · 产品设计

> 副标题：**识别下雨天，下雨天少出门**  
> 表面形态：个人生活节律 / 出行天气参考，与行情无关。

## 核心结论（龙 / 中 / 空 → 天气）

| 结论 | 天气文案 | 判定 |
|------|----------|------|
| **龙** | 天气不错 · 宜出门 | `displayScore > 70` |
| **中** | 多云 · 带伞 | 30 ≤ 分数 ≤ 70 |
| **空** | 下雨天 · 不出门 | `displayScore < 30` |

## 页面

- **今日**：大字天气结论 + 副文案 + 与君共勉 + 分享图
- **历史**：日期 + 天气结论（无涨跌、无分数）
- **我的**：登录（可选）、每日提醒、关于、说明

## 后端

复用 `server/` 同一套 API，Lite 仅消费 `today` / `history` / 订阅 / 登录接口。

## 目录

独立仓库路径：`miniprogram-lite/`，与完整版小程序、`web/` 并列。
